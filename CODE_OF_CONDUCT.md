# Code of Conduct

This project follows the
[Contributor Covenant Code of Conduct v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Short version

- Be respectful. Treat others the way you'd want to be treated in a code
  review.
- Disagree on technical grounds, not personal ones.
- Harassment, discrimination, and personal attacks are not tolerated.
- If something feels off, contact the maintainers via GitHub private
  message or by opening a private security-style report.

## Enforcement

Maintainers may remove comments, close issues, or block users without
warning for behavior that violates this Code of Conduct. Repeat or
egregious offenses lead to permanent bans.

This is a small personal project. We don't have a community team — just
common sense and the full Contributor Covenant text linked above.
